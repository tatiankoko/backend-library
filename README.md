# Сервер для библиотеки в которой есть читатели и книги

## Читатели

- `POST /users` — создать читателя.
- `GET /users` — список читателей.
- `GET /users/:user_id` — один читатель.
- `PATCH /users/:user_id` — обновить читателя.
- `DELETE /users/:user_id` — удалить читателя.

Если у читателя взяты книги, то удалить такого читателя нельзя.

## Книги

- `POST /books` — создать книгу.
- `GET /books` — список книг.
- `GET /books/:book_id` — одна книга.
- `PATCH /books/:book_id` — обновить книгу.
- `DELETE /books/:book_id` — удалить книгу.

Взятую книгу удалить нельзя.

## Выдача и возврат книг

- `GET /users/:user_id/books` — список книг, взятых читателем.
- `POST /users/:user_id/books` — взять книгу, body: { "book_id": "..." }.
- `DELETE /users/:user_id/books/:book_id` — отдать книгу.

При успешной выдаче сервер возвращает `201` и объект книги. При успешном возврате сервер возвращает `204` без тела. Если читатель или книга не найдены, возвращается `404`; если книга уже выдана или её возвращает не тот читатель — `409`.
